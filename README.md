<h2 align="center">🎬 ClypDat</h2>

<p align="center">
  <b>A game clip recorder and editor for Windows.</b><br />
  It keeps the last few minutes of gameplay in a rolling buffer, so one hotkey saves the moment<br />
  that <i>already happened</i> — then trims it and sends it, with no account and nothing to pay for.
</p>

  <tr>
    <td align="center" width="200">⚡<br /><b>Capture</b><br /><sub>DXGI desktop duplication<br />straight into NVENC</sub></td>
    <td align="center" width="200">✂️<br /><b>Edit</b><br /><sub>FFmpeg-backed trimming,<br />waveforms, multi-track audio</sub></td>
    <td align="center" width="200">🎯<br /><b>Auto-clip</b><br /><sub>CS2 and Dota kills caught<br />from the game's own events</sub></td>
