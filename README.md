### ClypDat

A game clip recorder and editor for Windows. It keeps the last few minutes of gameplay in
a rolling buffer, so a hotkey saves the moment that already happened — then trims and
shares it without an account, a subscription, or an ad in sight.

Under the hood it is a native DXGI capture pipeline feeding NVENC or libx264, an
FFmpeg-backed editor, and an updater that verifies a signed manifest before it will
install anything.

→ **[ClypLabs/ClypDat](https://github.com/ClypLabs/ClypDat)** · [clypdat.xyz](https://clypdat.xyz)

### What I work with

Day to day that means C# and .NET, Avalonia for the interface, Direct3D and FFmpeg for
the parts that touch pixels, and TypeScript with Next.js for anything on the web.
